# GhostMessenger — Resurrection

## Credits request description

Resurrection — I plan to build GhostMessenger, a modern reimagining of the retired MSN / Windows Live Messenger experience as a workspace for a small AI team. A familiar buddy list, presence indicators, conversation windows, file transfers, and nudges will help users coordinate three assistants: a researcher, a writer, and a reviewer. The first workflow will turn material from a public GitHub repository into a source-linked project introduction that the user can revise, approve, and download as Markdown. I plan to use Kiro specs, steering, and development workflows to build and validate the application.

## One-line pitch

Bring the buddy list back to life as a small AI team that researches, writes, and reviews your next project introduction.

## Honesty and attribution

This description states the planned work. There is no working demo yet. The new app will use original branding and assets, will not reconnect to the retired Messenger service, and will disclose reused libraries or other pre-existing work. Actual Kiro usage will be documented after it occurs.
