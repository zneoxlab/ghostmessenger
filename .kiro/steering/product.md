# Product steering

GhostMessenger is a new Kiroween 2026 Resurrection project. Its purpose is to revive messenger-era interaction as a useful way for one person to manage three AI assistants.

The first workflow is bounded: public GitHub repository material → sourced research notes → project introduction draft → review → human approval → Markdown export.

Use the buddy list, presence, conversations, file handoffs, and nudges to communicate real work and human decisions. Prefer a complete, understandable workflow over additional roles, decorative activity, or open-ended autonomous programming.

Never invent source evidence or report simulated progress as a real model run. Keep the user's approved artifact immutable and export the same content that was approved. Communicate with the project owner in Chinese; keep the main demo and judge-facing documentation in English.
